### Layers

There are 2 layers associated with editor:

1. Over Layer

It is added to document.body. It is used for popup covering whole screen or another, external page elements. Should be displayed above everything.
Can be modal or not.

It has class: .kb--over-layer
Can be accesed by: `editor.ci.get('overlayer');`

2. Top Layer

It is added to .kb-editor element. It is used for popup covering editor but below another, external page elements. Eg hover for part of text which is covered by dropdown menu from main page toolbar.
Can be modal or not.

It has class: .kb--top-layer
Can be accesed by: `editor.ci.get('toplayer');`

Overlayer/toplayer have following methods:

* ui.createPopup(tagName: string, opts) - creates element within layer. When ancestor is removed it removes all its children.
* anchorElement
